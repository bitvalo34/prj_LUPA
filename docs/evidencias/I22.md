# I22 — Prueba offline temprana

**Fecha:** 23 de septiembre de 2026  
**Rama de trabajo:** `feature/i22-offline-validation`  
**Base probada:** `f5dee50`  
**Entorno:** Ubuntu 24.04.3 LTS sobre WSL2

## Objetivo

Validar tempranamente que LUPA puede construirse, arrancar, navegar e importar una
imagen sin acceso a Internet, usando únicamente herramientas, recursos y
dependencias locales. También comparar diseño con implementación y actualizar
arquitectura/contrato.

Esta evidencia no sustituye instalación desde cero, empaquetado final ni pruebas de
rendimiento.

## Cero peticiones externas y navegación

Se abrió una carga nueva desde:

```text
http://127.0.0.1:8081/
```

con frontend servido por Java, sin Vite.

Network del navegador mostró únicamente recursos del servidor local:

- documento `127.0.0.1`;
- JS;
- CSS;
- Worker;
- `/api/catalog`;
- `/lupa` con estado 101.

Los zooms, pans, detalle y foco no crean peticiones HTTP por tesela: viajan como
mensajes dentro del WebSocket persistente `/lupa`.

La traza del visor confirmó VIEW/PLAN/TILE/DONE/ACK_STATE durante navegación y
terminó sin trabajo pendiente ni error bloqueante.

URLs W3C encontradas como cadenas dentro del bundle React corresponden a namespaces
de SVG/MathML/XML y no aparecieron como solicitudes Network de la aplicación.

No se encontró Service Worker.

### Hallazgo no bloqueante

Chrome mostró un warning de `preventDefault` dentro de un passive event listener.
El recorrido continuó y la sesión terminó sin error de protocolo. Se registra como
mejora de frontend no bloqueante.

## Comparación diseño vs implementación

| Aspecto | Diseño documentado | Implementación real | Diferencia | Acción |
|---|---|---|---|---|
| Backend | Java 20/21 asíncrono | Java 21 + NIO.2 | concreción | documentada |
| Frontend | HTML/CSS/JS sin framework en avance | React + TS + Vite | decisión válida | arquitectura actualizada |
| HTTP/WS | servidor único | HTTP + RFC6455 propio en Java | consistente | documentado |
| Confirmación | RELEASE | STA/ACK_STATE; RELEASE compatible | evolución de contrato | addendum actualizado |
| Fairness | turnos/concurrencia generales | DRR por bytes | concreción E22 | documentado |
| Épocas | intención creciente | implementadas y probadas | consistente | sin acción |
| Foco/niveles | uniform/focus, detail offset | implementado | consistente | sin acción |
| Worker | previsto | Worker local + Canvas | consistente | arquitectura actualizada |
| Caché | acotada | JPEG 128 MiB + buffers 16 MiB | concreción | documentado |
| Heartbeat | no fijado en S19 | PING/PONG + timeouts | contrato desactualizado | addendum actualizado |
| Importación | local + libvips | Java + ProcessBuilder + libvips | consistente | verificado offline |
| Descubrimiento | catálogo publicado | recarga manual sin reinicio Java | concreción A22 | documentado |
| Offline | cero objetos externos | build/carga/navegación/import offline | objetivo cumplido | evidencia I22 |
