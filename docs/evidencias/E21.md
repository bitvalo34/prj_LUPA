## Recorrido técnico E21

Herramienta:

```text
gt.lupa.tools.LupaE21Probe
```

Objetivos del probe:

1. HELLO/WELCOME;
2. OPEN/MANIFEST real;
3. VIEW uniform offset 0;
4. VIEW uniform offset -1;
5. BAD_VIEW con epoch alto sin consumir la época;
6. VIEW focus;
7. RELEASE duplicado/desconocido sin afectar continuidad;
8. VIEW uniform offset -2;
9. deliveryId estrictamente creciente;
10. hash SHA-256 de cada JPEG contra el archivo publicado cuando se proporciona data-root;
11. invariante local de ventana/reservas durante el recorrido;
12. DONE coherente con TILE recibidos.

## Resultado observado

Verificado en el WSL de Erwin con `demo-auxiliar/v1` y `data-root` real:

```text
E21_PROBE ws=open subprotocol=lupa.v1
WELCOME window=1048576 maxTile=262144 maxInFlight=16
MANIFEST epoch=1 image=demo-auxiliar/v1 size=1096x815 maxLevel=3 tileSize=256
PLAN epoch=2 mode=uniform offset=0 applied=3 context=3
DONE epoch=2 sentTiles=21 levels={0=1, 3=20} credit=OK
PLAN epoch=3 mode=uniform offset=-1 applied=2 context=2
DONE epoch=3 sentTiles=6 levels={2=6} credit=OK
BAD_VIEW epoch=100 preserved session; next accepted epoch will be 4
PLAN epoch=4 mode=focus offset=0 applied=3 context=2
DONE epoch=4 sentTiles=12 levels={2=6, 3=6} credit=OK
RELEASE duplicate=1 and unknown=2000000000 sent; no client credit was added
PLAN epoch=5 mode=uniform offset=-2 applied=1 context=1
DONE epoch=5 sentTiles=2 levels={1=2} credit=OK
E21_PROBE SUCCESS views=4 maxReserved=24265 maxPending=1 creditInvariantChecks=87
```

Interpretación comprobada:

- `uniform offset=0` aplicó z=3 y contexto z=3;
- `detailOffset=-1` bajó realmente a z=2;
- `detailOffset=-2` bajó realmente a z=1;
- el `BAD_VIEW epoch=100` no consumió la época: posteriormente se aceptó `epoch=4`;
- `focus` produjo detalle z=3 y contexto z=2, con 6 teselas de cada nivel;
- después de RELEASE duplicado y desconocido la sesión continuó y completó `epoch=5`;
- cada DONE coincidió con la cantidad de TILE observados por el probe;
- cada plan terminó con `credit=OK`;
- el probe alcanzó SUCCESS con `data-root` proporcionado, por lo que las verificaciones de JPEG decodificable, dimensiones y SHA-256 contra las teselas publicadas no detectaron discrepancias;
- las aserciones internas de monotonicidad de `deliveryId` tampoco detectaron reutilización ni retroceso.

No se registraron JPEG ni buffers completos.

## Integración A21

El contrato operativo está documentado en:

```text
docs/A20-E20-integration.md
```

sección “E21 addendum — contrato operativo para A21”.

A21 debe respetar especialmente:

- viewport sin letterboxing;
- rect/focus en coordenadas originales;
- radiusPx físico;
- PLAN como fuente del nivel efectivo;
- contexto antes de detalle;
- descarte de épocas antiguas antes/después de decode;
- RELEASE de entregas antiguas;
- DONE != composición terminada;
- reconexión antes de agotar identificadores.
