## Recorrido técnico E21

Herramienta:

```text
gt.lupa.tools.LupaE21Probe
```

Objetivos del probe:

1. HELLO/WELCOME;
2. OPEN/MANIFEST real;
3. VIEW uniform offset 0;
4. VIEW uniform offset -1;
5. BAD_VIEW con epoch alto sin consumir la época;
6. VIEW focus;
7. RELEASE duplicado/desconocido sin afectar continuidad;
8. VIEW uniform offset -2;
9. deliveryId estrictamente creciente;
10. hash SHA-256 de cada JPEG contra el archivo publicado cuando se proporciona data-root;
11. invariante local de ventana/reservas durante el recorrido;
12. DONE coherente con TILE recibidos.

## Integración A21

El contrato operativo está documentado en:

```text
docs/A20-E20-integration.md
```

sección “E21 addendum — contrato operativo para A21”.

A21 debe respetar especialmente:

- viewport sin letterboxing;
- rect/focus en coordenadas originales;
- radiusPx físico;
- PLAN como fuente del nivel efectivo;
- contexto antes de detalle;
- descarte de épocas antiguas antes/después de decode;
- RELEASE de entregas antiguas;
- DONE != composición terminada;
- reconexión antes de agotar identificadores.
